# TikTok Live Overlay

Overlay desktop untuk streamer TikTok LIVE yang guna **OBS Studio**.

App ini paparkan chat, gift, viewer, like, dan status LIVE dalam satu tetingkap kecil yang boleh diletak di atas skrin atau ditangkap sebagai sumber dalam OBS. Tujuan utama: baca komen dan pantau gift tanpa perlu tengok skrin TikTok penuh.

Dibuat oleh **Kamilsemm**.

## Untuk siapa

- Streamer yang live di TikTok
- Yang guna OBS / streaming software
- Yang mahu pantau interaksi penonton sambil fokus pada kandungan live

## Kelebihan

- **Chat LIVE** — komen muncul terus, senang dibaca semasa stream
- **Gift diterima** — senarai gift, gambar gift, dan jumlah coin
- **Viewer yang masih dalam live** — nampak siapa masih stay
- **Banner join & like** — pemberitahuan join/like tidak mengganggu feed komen
- **Bunyi gift** — boleh tukar bunyi, volume, atau fail sendiri
- **Sentiasa di atas + klik tembus** — sesuai overlay di atas game/OBS
- **3 bahasa** — English, Malaysia, Indonesia
- **Auto sambung** — cuba sambung semula ke username terakhir
- **Kemas kini** — semak versi baru dari GitHub Releases

## Cara guna dengan OBS

1. Pasang `TikTok Live Overlay Setup` dari [Releases](https://github.com/kamilsem/tiktok-live-overlay/releases)
2. Buka app, masukkan username TikTok LIVE, tekan Sambung
3. Dalam OBS, tambah sumber **Window Capture** (atau Display Capture) → pilih tetingkap TikTok Live Overlay
4. Susun saiz/kedudukan overlay mengikut layout stream anda
5. Hidupkan **Klik tembus** dalam Settings jika mahu klik tembus ke game di belakang
